# Case studies

Write-ups of larger products I have built. The code for these projects is private, so each page covers the problem, the design, the decisions and the results, and what I would change. **There is no source code, customer data or personal data in this repository.**

| Project | What it is | Status |
|---|---|---|
| [Free My TV](free-my-tv.md) | A fast custom home screen for a slow Google TV: a fork of an open-source launcher | v1.0 complete, personal use |
| [Health Journal](health-journal.md) | A single-user web app that logs meals and estimates macros with an AI model | Ongoing polish |

## How these were built

All of these projects were built with an AI coding assistant ([Claude Code](https://claude.com/claude-code)). My part was the problem definition, the design and decision records, the review, and the testing on real hardware or real use. I mention it here so that the numbers and claims on these pages are read for what they are: my own measurements on my own devices, not benchmarks from an independent lab.

Where a project builds on someone else's open-source work, the page says exactly what was theirs and what was mine.
